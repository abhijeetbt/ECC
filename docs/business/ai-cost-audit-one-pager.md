A flat-fee, one-time engagement: we scan your Claude Code setup and codebase
for the exact patterns that quietly inflate an AI bill, verify every finding

Built for small teams already paying for Claude or GPT usage who don't have

**3–5 days** from kickoff to report · **8 checks** across config and code ·

## What's covered

- Claude Code configuration review — default model, thinking-token budget,
  subagent model, MCP server count
- Source-code pattern scan — hardcoded expensive models with no routing,
  missing prompt caching, retries that don't distinguish transient from
  permanent failures, no budget tracking
- Current tracked spend by model, if a cost tracker is already running
- Written report, findings ranked by likely dollar impact, each with a
  concrete fix
- 15-minute readout call to walk through the findings together

**How your code stays yours.** The scan is heuristic and runs locally
against your repository during the engagement — nothing is uploaded to a
third party or sent to a model to be read.

## How it runs

1. **Discovery call** (Day 0, 15 min) — confirm scope and get read access to
   the relevant code and Claude Code config.
2. **Audit run** (Day 1) — automated scan of settings and source patterns,
   run against your machine or repo.
3. **Manual review** (Day 2–3) — every finding checked by hand and ranked by
   expected dollar impact before it reaches you.
4. **Report + readout** (Day 3–5) — written report delivered, followed by a
   short call to walk through what to fix first.
5. **Implementation** (optional) — we make the changes directly, scoped and
   priced separately from the audit.
